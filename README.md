# Divergence — 会社紹介サイト

HTML・CSS・JavaScriptだけで作られた、シンプルな1ページ構成の会社紹介Webサイトです。

「人と企業の可能性を、もっと前へ。」をメインコピーに掲げる、Divergenceのブランドサイトです。

## 起動方法

### すぐに確認する

`index.html` をブラウザで直接開いてください。

### ローカルサーバーを使う

リポジトリのルートで次のコマンドを実行します。

```bash
python3 -m http.server 8000
```

その後、ブラウザで [http://localhost:8000](http://localhost:8000) を開いてください。

## ファイル構成

- `index.html` — ページの構造とコンテンツ
- `style.css` — レイアウト、配色、レスポンシブデザイン
- `script.js` — モバイルメニュー、スクロール演出、コピーライト年の更新

追加のパッケージやビルド作業は必要ありません。
